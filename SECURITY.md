# Security Policy

This tool runs locally, collects no data, sends nothing anywhere, and needs no key or secret. It only reads the Markdown files or directories you name, and it never changes a file. It writes nothing except the report on standard output (and usage errors on standard error).

If you find a case where the tool changes a file, or reports an image or line that does not match the real file, please open an issue describing the exact commands and input. Do not include any real secret in the report.
